# assets

Images used by the README pages. Nothing here is part of a release, and the
updater never reads this folder.

## brand/

| File | What it is |
|---|---|
| `gameque-mark-64.png` | The Gameque mark, taken unchanged from the application icon (64×64 frame) |
| `gameque-mark-128.png` | The same pixels doubled, so the mark stays sharp at README size |

The mark is the existing application icon. No new logo is drawn here. A larger
master version of the mark, or a hero banner, can replace these once one exists.

## screenshots/

Real screenshots of Gameque on Windows only — no mockups. Expected files, which the
READMEs will reference once they are added:

| File | Shows |
|---|---|
| `dashboard.png` | The main window: status, VALORANT card, now playing |
| `settings.png` | Settings: pause point, music source, game modes |
| `update.png` | The update banner, or Settings → Updates with an update available |

Recommended: the app window at 100% display scale, dark theme as shipped, cropped to
the window, PNG, no personal information in the track or account fields.
