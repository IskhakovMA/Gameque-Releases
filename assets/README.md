# assets

Images used by the README pages. Nothing here is part of a release, and the
updater never reads this folder.

## brand/

| File | What it is |
|---|---|
| `gameque-mark-64.png` | The Gameque mark, taken unchanged from the application icon (64×64 frame) |
| `gameque-mark-128.png` | The same pixels doubled, so the mark stays sharp at README size |

The mark is the existing application icon. No new logo is drawn here.

## hero.png

Promotional artwork for the top of both READMEs — not an application screenshot.
Shown at its natural proportions, never stretched: GitHub scales it down to fit
narrow screens.

## screenshots/

Real screenshots of Gameque captured on Windows — no mockups.

| File | Shows | Used in |
|---|---|---|
| `dashboard.png` | The main window: status, VALORANT card, now playing | README, full width |
| `settings.png` | Settings: pause point, music source, game modes | README, half width |
| `update.png` | The update banner, or Settings → Updates with an update available | README, half width |
| `about.png` | The About screen | Kept for later; not on the README, to keep it uncluttered |

Recommended: the app window at 100% display scale, dark theme as shipped, cropped to
the window, PNG, no personal information in the track or account fields.
